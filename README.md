## Featured work

### [01 — Aviation Disruption Intelligence](https://github.com/ozenbozkurt/aviation-disruption-intelligence)

**Real European aviation performance data → reproducible analysis → operational insights.**

- Integrates official **EUROCONTROL Data app beta API** daily network-performance observations.
- Persists and transforms observations with **Python, DuckDB, SQL, CSV and Parquet**, including Power BI-ready exports.
- Presents a **30-day Germany, September 2026** case study using ATFM delay per flight and arrival/departure punctuality.
- Documents a transparent, period-relative disruption index, the difference between measured signals and causal hypotheses, and next-step operational investigations.
- Includes **FastAPI**, automated Windows/Linux tests, and a deployed analytical dashboard.

**Explore:** [Live dashboard](https://aviation-disruption-intelligence.onrender.com/dashboard/germany-september-2026) | [Case-study methodology and findings](https://github.com/ozenbozkurt/aviation-disruption-intelligence/blob/main/case-studies/germany-september-2026.md) | [Source code](https://github.com/ozenbozkurt/aviation-disruption-intelligence)

*Scope note:* The network-performance dashboard analyzes a historical EUROCONTROL dataset. The separate weather-dependent live route endpoint currently encounters provider rate limits and should not be presented as a fully available feature. This project is for portfolio analytics—not dispatch, flight safety, or go/no-go decisions.

### [02 — Flight Delay Operations Intelligence](https://github.com/ozenbozkurt/flight-delay-operations-intelligence)

**Reproducible U.S. flight-delay CSV analysis.**

- Python CLI and pandas-based analysis of BTS-style flight-delay data.
- Delay metrics, airport and carrier comparisons, route summaries, and optional visualizations.
- Regression tests and GitHub Actions CI across Windows and Linux.
- Documented releases and external open-source contribution review.

**Explore:** [Repository and usage guide](https://github.com/ozenbozkurt/flight-delay-operations-intelligence)

*Scope note:* Memory-bounded CSV processing is an open contribution under review, not a released capability.
